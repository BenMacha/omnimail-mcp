# Contribuer

- Commits au format [Conventional Commits](https://www.conventionalcommits.org/fr/) (`feat:`, `fix:`, `docs:`…).
- Mettre à jour `CHANGELOG.md` dans chaque pull request.
- Jamais de vrais identifiants ni de vrais mails dans les tests : utiliser le serveur IMAP de test en conteneur.
- Toute nouvelle action d'écriture doit avoir ses annotations MCP et passer par les garde-fous (plan + confirmation si destructive).
- Les diagrammes sont en Mermaid dans les fichiers Markdown.
